# 안녕하세요! 👋

### AI·데이터 기반 서비스 개발을 공부하고 프로젝트로 구현하고 있습니다.

Python을 활용한 데이터 수집·분석부터 머신러닝과 AI API를 활용한 웹 서비스 개발까지 경험하고 있습니다. 단순히 모델이나 기능을 만드는 데 그치지 않고, 실제 사용자 화면과 연결하고 오류·예외 상황을 개선하는 과정에 관심이 있습니다.

📚 **포트폴리오:** [Notion에서 보기](https://app.notion.com/p/40c6d9f6c5f581a883ddcf73f791846d)

## 🛠️ Tech Stack

- **Language / Data:** Python, Pandas, SQL, JSON, CSV
- **AI / ML:** Scikit-learn, K-Means, YOLO-World, OpenAI API
- **Backend:** FastAPI, Flask, SQLAlchemy
- **Frontend:** React, JavaScript, HTML, CSS
- **Database:** PostgreSQL, SQLite (테스트)
- **Collaboration / Deployment:** Git, GitHub, Docker

> 위 기술은 프로젝트 및 학습 과정에서 사용한 기술이며, 기술별 숙련도가 동일하다는 의미는 아닙니다.
